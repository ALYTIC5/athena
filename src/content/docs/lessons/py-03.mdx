<Chunk n={1} title="Scope and closures">

A **scope** is the part of a program where a name can be used. Inside a function, Python looks a name up in this order, called the **LEGB rule**: Local (the function itself), Enclosing (any functions around it), Global (the module) and Built-in (such as `len`). It stops at the first match. Assigning to a name inside a function makes it local for the whole function, unless you declare it `global` or `nonlocal`.

A **closure** is an inner function that keeps using names from its enclosing function after that function has returned. It remembers the variable, not the value the variable had when the function was created. This is **late binding**, and it is why functions made in a loop all see the loop variable's last value.

**Worked example.** A counter that remembers its count, then the loop trap and its fix.

```python
def make_counter():
    count = 0
    def next_id():
        nonlocal count       # rebind the enclosing count, not a new local one
        count += 1
        return count
    return next_id

ids = make_counter()
print(ids(), ids())          # 1 2: the count survives between calls
```

```python
late = [lambda: name for name in ["amara", "bayu"]]
print([f() for f in late])   # ['bayu', 'bayu']: both read `name` when called, after the loop
fixed = [lambda name=name: name for name in ["amara", "bayu"]]
print([f() for f in fixed])  # ['amara', 'bayu']: a default is stored when the lambda is created
```

Without `nonlocal`, `count += 1` would make `count` local to `next_id` and fail:

```python nocheck="raises UnboundLocalError on purpose"
total = 0
def add(n):
    total += n    # UnboundLocalError: total is local here, because it is assigned
```

- "A closure copies the variable's value." It keeps the variable, so later changes are seen, and loop variables are all seen at their last value.

<Chunk n={2} title="Flexible arguments and decorators">

`*args` collects extra positional arguments into a tuple, and `**kwargs` collects extra keyword arguments into a dict. Parameters after a bare `*` (or after `*args`) are **keyword-only**: callers must name them. In a call, `f(*items, **options)` does the reverse and spreads a sequence and a dict into arguments.

Functions are objects, so you can pass them to other functions and return them. A **decorator** is a function that takes a function and returns a function, usually a wrapper that adds behaviour. Writing `@deco` above `def f` means `f = deco(f)`. The wrapper takes `*args, **kwargs` so it accepts any call, returns the original's result, and `@functools.wraps(func)` copies the original's name and docstring onto it.

A decorator with a setting is a function that returns the decorator, used as `@timed(clock)`. In the exercise, `clock` is a function that returns the current time.

**Worked example.** A decorator that logs every call.

```python
import functools

def log_calls(func):
    @functools.wraps(func)                 # keep the original name and docstring
    def wrapper(*args, **kwargs):          # accept any call
        print("calling", func.__name__, args, kwargs)
        return func(*args, **kwargs)       # pass everything on, and return the result
    return wrapper

@log_calls                                 # same as: book = log_calls(book)
def book(name, *, slot):                   # slot is keyword-only
    return name + " at " + slot

print(book("amara", slot="09:00"))         # calling book ('amara',) {'slot': '09:00'} / amara at 09:00
print(book.__name__)                       # book: wraps kept the name
```

A decorator with a setting adds one more level.

```python
import functools

def prefix(tag):                           # the factory: takes the setting
    def decorator(func):                   # the real decorator
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            return tag + func(*args, **kwargs)
        return wrapper
    return decorator

@prefix("VIP: ")                           # prefix("VIP: ") runs first and returns the decorator
def greet(name):
    return "hello " + name

print(greet("amara"))                      # VIP: hello amara
```

<Chunk n={3} title="Iterators and generators">

A `for` loop works on any **iterable**. It asks the object for an **iterator** with `iter()`, then calls `next()` on it until it raises `StopIteration`. A list gives a fresh iterator each time. A generator is its own iterator, so it can be used only once.

A **generator function** is a function that contains `yield`. Calling it runs none of the body and returns a generator. Each `next()` runs the body up to the next `yield`, hands that value over and pauses with all local variables kept. A generator makes items on demand, so it can handle a file of ten million records without holding them all in memory.

`itertools` has tools for iterators, such as `islice` (take the first few items lazily) and `chain` (join iterators). From Python 3.12, `itertools.batched` groups items into tuples.

**Worked example.** A generator that reads call records one at a time.

```python
def read_calls(lines):
    for line in lines:
        caller, hour = line.split(",")
        yield caller, int(hour)       # hand one record over, then pause here

gen = read_calls(["amara,9", "bayu,14", "chen,10"])
print(next(gen))                      # ('amara', 9): the body ran up to the first yield
print(list(gen))                      # [('bayu', 14), ('chen', 10)]: the rest
print(list(gen))                      # []: a generator is used up after one pass
```

```python
import itertools

readings = (n * 10 for n in range(1_000_000))   # a generator expression: nothing is made yet
print(list(itertools.islice(readings, 3)))      # [0, 10, 20]: only three items are produced
```

<Callout type="misconception" title="Common misconceptions in chunk 3">

- "Calling a generator function runs it." It returns a generator. Nothing runs until the first `next()`.
- "A generator is a list that is made later." It has no length, no indexing and no second pass.
- "`return` and `yield` both end the function." `return` ends it. `yield` pauses it.
